4 x d_model^{2}

3 d_ff x d_{model}

48*(4 x d_model^{2}+ 3 d_ff x d_{model})

for embedding and outembedding it is 

2 *(size_vocab *d_model)

we can neglect the rms norm parameters, so we end up with

48*(4 x d_model^{2}+ 3 d_ff x d_{model})+2 *(size_vocab *d_model)

Input embedding lookup
O(n)
For each of L blocks:
    Q projection Q x  (d,d)(d,n) -> 2d^{2}n
    K projection K x  (d,d)(d,n) -> 2d^{2}n
    V projection      (d,d)(d,n) -> 2d^{2}n
    Q–K score product (n,d)(d,n)-> 2n^{2}d
    attention-probability–V product (n,n)(n,d) -> 2n^{2}d
    output projection (d,d)(n,d)-> 2d^{2}n
    W1 projection (d_ff d_model) (n d_model)-> 2 d_ff d_model n
    W3 projection (d_model d_ff) (n d_ff)-> 2 d_ff d_model n
    W2 projection (d_ff d_model) (n d_model)-> 2 d_ff d_model n

Final vocabulary projection (vocab_size d_model) (d_model n)-> 2 vocab_size d_model n

96*(3  d_ff d_model n +4*d^{2}n +2n^{2}d)+2 vocab_size d_model n
